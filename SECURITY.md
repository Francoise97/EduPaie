# Politique de securite

## Versions supportees

| Version | Supportee |

## Signaler une vulnerabilite

Merci de signaler les vulnerabilites de securite a :
contact@mavictoire.tg

Ne pas ouvrir d'issue publique pour les problemes de securite.

## Mesures de securite du projet

- Base de donnees locale (pas de reseau)
- Aucune donnee personnelle transmise
- Mots de passe : non stockes
