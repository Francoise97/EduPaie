## Typographie

- Police : Segoe UI Variable Display
- Fallback : Segoe UI, Arial, sans-serif
- Titres : 24px, bold (700)
- Texte courant : 13px
- Boutons : 14px, semi-bold (600)

## Espacements

- Padding general : 20px
- Padding cartes : 14px
- Espacement vertical : 14px
- Border radius : 6-10px

## Composants

### Cartes
- Fond blanc
- Bordure 1px #E2E8F0
- Border radius 10px
- Padding 14px

### Boutons
- Hauteur minimale : 34px
- Border radius : 6px
- Padding : 10px 18px

### Tableaux
- En-tete : fond gris clair
- Alternance de lignes
- Selection : bleu clair

## Icônes

Les icônes sont des emojis Unicode :
- 👥 Eleves
- 💰 Paiements
- 📄 Recus
- ⚙️ Parametres
- 📊 Tableau de bord
