# Accessibilite - EduPaie

## Principes

Application concue pour etre accessible au plus grand nombre.

## Contraste

Toutes les couleurs respectent le ratio WCAG AA.

| Couleur | Fond | Contraste |
|---------|------|-----------|
| #1E3A8A | #FFFFFF | 10.7:1 |
| #10B981 | #FFFFFF | 3.4:1 |
| #EF4444 | #FFFFFF | 4.5:1 |

## Taille de police

- Titres : 24px
- Texte courant : 13px
- Boutons : 14px

Toutes les tailles sont lisibles.

## Navigation clavier

| Raccourci | Action |
|-----------|--------|
| Tab | Element suivant |
| Shift+Tab | Element precedent |
| Enter | Valider |
| Esc | Annuler |
| Alt+F4 | Quitter |

## Ergonomie

- Boutons larges (34px min)
- Espacements generreux
- Messages explicites
- Confirmations pour actions critiques

## Adaptations

- Fenetre redimensionnable
- Minimim 1100x700
- Police systeme (Segoe UI)

## Ameliorations futures

- Mode daltonien
- Taille de police ajustable
- Mode sombre
