# Glossaire - EduPaie

## Termes metier

**Eleve** : Personne inscrite dans l'etablissement.

**Frais de scolarite** : Montant total du par l'eleve sur l'annee.

**Paiement** : Versement effectue par l'eleve.

**Solde** : Montant restant du (frais - paiements).

**Statut** :
- Non paye : Aucun paiement
- Partiellement paye : Paiement < frais
- Solde : Paiement = frais

**Recu** : Document numerote emis apres un paiement.

**Annulation** : Marquer un paiement comme annule (soft delete).

## Termes techniques

**SQLite** : Base de donnees legere, mono-fichier.

**PySide6** : Framework Qt pour Python.

**reportlab** : Bibliotheque de generation PDF.

**PyInstaller** : Outil de packaging en executable.

**Repository** : Couche d'acces aux donnees.

**Service** : Couche de logique metier.

**Widget** : Element d'interface graphique.

**Migration** : Modification de la structure de la base.

**Soft delete** : Marquer comme supprime sans effacer.

## Sigles

**MCD** : Modele Conceptuel de Donnees.

**MLD** : Modele Logique de Donnees.

**DAO** : Data Access Object.

**CRUD** : Create, Read, Update, Delete.

**QSS** : Qt Style Sheets (comme CSS).

**FCFA** : Franc CFA.
